## 1. 这个项目是什么（30 秒版）

> **一个由「本」统筹的 AI 团队办公室。**
> 三个智能体同事各司其职，人只跟「本」说话；所有会改动项目正式数据的结论，**先过人审，再落库**。

四个角色：

| 角色 | 名字 | 干什么 |
|---|---|---|
| **主管** | **本** | 对人沟通、看全部同事产出、派活、启动同事的服务 |
| 会议 | **译** | 把会上说的话译成任务、负责人、排期 |
| 画像 | **衡** | 说清每个人做了什么、扛了多难、有什么风险 |
| 画图 | **绘** | 把项目数据或一句话画成可交互的图

### 5.2 · 主管入口：悬浮像素头像 + 对话框 ✅

新增 5 个文件、改 3 个：

| 文件 | 作用 |
|---|---|
| `frontend/src/api/supervisor.js` | `POST /chat` + `GET /chat/stream`（**自写 SSE 解析**，见下） |
| `frontend/src/utils/supervisorTimeline.js` | 事件 → 人话（**按代码**，不按设计文档） |
| `frontend/src/stores/supervisor.js` | 会话 / 消息 / 时间轴 / 连接四态 |
| `frontend/src/components/SupervisorAvatar.vue` | 右下角悬浮像素头像 |
| `frontend/src/components/SupervisorChat.vue` | 对话框：消息流 + 过程时间轴 |
| `frontend/src/App.vue` | 挂载（与 `ToastBox` / `LoginDialog` 同级）|
| `frontend/src/styles/index.css` | 追加样式块（沿用零圆角 + 硬描边）|
| `frontend/src/constants.js` | `SUPERVISOR_SESSION_KEY` |

**三处实现决定（为什么这么做）**

1. **不用原生 `EventSource`** —— 它不能带自定义请求头，而本服务鉴权是
   `Authorization: Bearer`（契约 §2.5：身份只来自 JWT，不允许退化成查询参数）。
   改用 `fetch + ReadableStream` 手工解析 SSE，代价是重连自己做，收益是能带令牌。
2. **时间轴按 `run_id` 分组保留，不在新一轮清空** —— 清空的话上一轮"本找了谁"就翻不回去，
   那不叫过程可观测。
3. **头像四种状态而不是两种** —— 编排层挂了 / 平台后端挂了 / 没配模型密钥，这三种"不可用"
   用户要做的动作完全不同（起服务 / 起 Java / 配 API key），混成一种等于没提示。

**⚠️ 事件类型以代码为准，不以设计文档为准**

`docs/02-契约/主管智能体_工作流落地设计.md` §6 那张表写的 `plan.proposed` /
`dispatch.sent` / `run.progress` / `answer.final` —— **那套名字从未落地**。
真实清单是 `agent-orchestrator/app/events.py:EVENT_TYPES` 的 11 类：
`session.start` / `intent.routed` / `clarify.request` / `agent.dispatched` /
`tool.call` / `tool.result` / `model.step` / `agent.report` / `artifact.ready` /
`run.end` / `run.error`。载荷字段逐条对着 `_plan_phase` 与 `_run_loop` 核过。
（该表的修正留到 §7 ⑥ 「重写总线文档」时一并处理。）

**验收记录**

- `npm run build` → ✓ built in 6.94s
- 22 条纯函数冒烟全绿（SSE 帧解析 + 事件映射，含 `route=null ≠ 反问`、
  `logged=false` 要可见、未登记工具名原样显示三条易错分支）
- 浏览器冒烟：头像挂载于右下角、编排层未起时为灰态且输入框禁用、原导航未受影响
