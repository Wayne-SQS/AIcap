## 1. 这个项目是什么（30 秒版）

> **一个由「本」统筹的 AI 团队办公室。**
> 三个智能体同事各司其职，人只跟「本」说话；所有会改动项目正式数据的结论，**先过人审，再落库**。

四个角色：

| 角色 | 名字 | 干什么 |
|---|---|---|
| **主管** | **本** | 对人沟通、看全部同事产出、派活、启动同事的服务 |
| 会议 | **译** | 把会上说的话译成任务、负责人、排期 |
| 画像 | **衡** | 说清每个人做了什么、扛了多难、有什么风险 |
| 画图 | **绘** | 把项目数据或一句话画成可交互的图

## 3. 还没做的（按优先级，可直接认领）

### 🔴 P0 · 决定"是不是一个产品"

**① 悬浮像素头像 + 对话框**
- 干什么：右下角常驻「本」的像素头像，点开是对话框，能问项目情况、能派活给三个同事
- 依赖：后端 `/chat` + `/chat/stream` 已就绪，**只差前端**
- 工作量：纯前端，不碰后端
- 为什么最优先：没有它，"办公室"这个故事就只剩 PPT

**② 对话过程时间轴**
- 干什么：对话框内按 `seq` 渲染"本 → 找了谁 → 说了什么 → 拿回什么"
- 依赖：SSE 事件流（11 类信封）后端已就绪，前端零消费
- 工作量：和 ① 一起做，边际成本几乎为零

**③ 运行时证据校验**
- 干什么：把 `invented_assignment` / `invalid_evidence` / `incomplete_analysis` 三条检查移植进 ai-service 的 validate 节点
- 依赖：有原始实现可移植
- 工作量：唯一要动后端的一项，但改动面小

### 🟡 P1 · 决定"好不好用"

**④ 画像域后台消费者**

**⑤ 编排层进生产**
- 干什么：`deploy/compose.yaml` 加 orchestrator 服务 + nginx 加 `/orchestrator/` 路由（`proxy_buffering off`）

## 5. 明日计划（2026-10-14）

> 原则：**不动后端**。你已明确技术冻结，今天删老 Agent 也验证了删得干净。

### 第一步 · 钉死待删目录（约 10 分钟，零风险）

在 `backend/` 和 `legacy/` 各放一个 `DEPRECATED.md`，写清三件事：

1. 为什么归档（参考实现 / 被 `frontend/` 取代）
2. **唯一仍在用的东西**：`backend/docker-compose.yml` —— 它是本机起 MySQL(3307) + Qdrant(6333) 的现行方式，**删除前必须先迁移走**
3. 删除的前提条件：dev 编排迁到 `deploy/` 之后

> 这一步先做，是因为它是**防止未来再产生耦合**的最低成本手段——不花时间，但能让队友一进目录就知道"别往这儿加东西"。

### 第二步 · 主管入口：悬浮像素头像 + 对话框（主要工作）

新增 3 个文件 + 改 1 个：

| 文件 | 作用 |
|---|---|
| `frontend/src/api/supervisor.js` | 封装 `POST /chat` 与 `GET /chat/stream`（SSE） |
| `frontend/src/components/SupervisorAvatar.vue` | 右下角悬浮像素头像，点击展开/收起 |
| `frontend/src/components/SupervisorChat.vue` | 对话框：输入 + 消息流 + 事件时间轴 |
| `frontend/src/App.vue` | 挂在末尾，与 `ToastBox` / `LoginDialog` 同级 |

**实现要点：**

1. **头像**：像素风（沿用 `src/styles/index.css` 的自绘 CSS，方块 + 硬边 + 无圆角/无阴影），右下角常驻，可拖拽或固定
2. **SSE 消费**：用 `EventSource` 接 `/chat/stream`，**按 `seq` 排序**渲染，自带 `Last-Event-ID` 续传
3. **时间轴**：把 7 类事件映射成人话
   - `plan.proposed` →「我打算让译去做」
   - `dispatch.sent` →「已让译开始，编号 #123」
   - `run.progress` →「译正在分析…（第 3 步）」
   - `run.terminal` →「译完成了」
   - `answer.final` → 最终答复（带引用卡片）
4. **降级**：后端不可用时，头像显示灰态 + 提示「主管未连接」

**验收标准**：
- `npm run build` 通过
- 打开任意页面，右下角能看到「本」的头像
- 点开能输入，发出去能看到事件时间轴动起来
- 断网/后端挂掉时，头像变灰且不影响其他功能
