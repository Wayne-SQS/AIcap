# AI 办公室：沉浸式像素界面

2026-10-18，基于 `feat/agent-tool-layer` 的 `245fd8f` 继续设计。

## 用户确认的方向

- 沉浸式像素办公室，奶油原木与苔绿配色。
- 俯视 RPG 房间：主管在入口附近，三位同事分区办公，中间保留公共区和通道。
- 保留本、译、衡、绘的身份，使用全身像素人物与轻量待机、工作动效。
- 点击人物或工位打开右侧抽屉，背景办公室保持可见。
- 首屏只展示服务状态、待审核数和最近进展；详细过程收进抽屉。

## 页面与交互

- 房间由矢量像素元素绘制，包含木地板、窗景、书架、植物、饮水区、公共地毯和工位。
- 提案信箱沿用真实审核队列接口；读取失败显示未知数与重试，不显示伪造的零。
- 白板展示主管事件流中的最近进展，点击后按协作轮次查看完整记录。
- 本的抽屉复用 `SupervisorConversation`；和全站入口共用既有会话及 SSE，不创建第二套对话。
- 本的未发送草稿在关闭、再打开抽屉后保留；关闭不会中断主管事件流。
- 三位同事复用 `AgentWorkbench` 及原业务面板；提交分析归属衡。
- 抽屉支持 Escape、关闭按钮、点击遮罩关闭，关闭后焦点返回原触发按钮。
- 会议来源、分析类型等深链仍可直接定位会议抽屉，返回审核中心保留原有筛选。
- 抽屉内部切换同事，工作台标签支持方向键与 Home / End。
- 手机上使用紧凑项目选择器和横向功能导航；抽屉接近全屏。
- 支持暂停场景动效及系统 `prefers-reduced-motion`。

## 状态真实性

- 本的状态来自主管服务健康信息，工作动效来自 `sup.running`。
- 同事工位显示“工作台可查看”或“离线演示”，不把平台在线虚构为每位智能体正在工作。
- 过程记录及白板来自现有事件流，空状态不填假任务。
- 不改后端智能体、权限、审核或确认执行逻辑。

## 验证

在 `frontend/` 执行：

```powershell
npm run build
node node_modules/@playwright/test/cli.js test --config=playwright.office.config.js
```

7 项浏览器用例覆盖首屏、1440/1024/768/390 宽度、抽屉和草稿、键盘焦点、旧会议深链、旧审核返回、既有项目路由以及对话请求与 SSE 事件契约。接口由测试模拟；不把这些结果当作模型质量或完整后端运行验证。
