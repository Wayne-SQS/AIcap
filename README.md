# 爱管理 · 团队工作台

> 支持软件团队管理需求、安排任务、四视图联动与六项 AI 能力的协作平台 —— 像素风可交互原型。

## 这是什么

「爱管理」是一个面向小型软件研发团队的项目管理平台。本仓库是它的**前端可交互原型**，纯静态、零依赖，双击 `index.html` 即可在浏览器中打开使用。

## 功能视图

| 视图 | 说明 |
|---|---|
| ◈ 项目总览 | 故事/任务统计、3 个 Sprint 进度、里程碑、总完成度 |
| ▦ 用户故事看板 | 20 条故事拖拽、编辑、故事地图、搜索筛选、JSON/CSV 导出 |
| ▤ 甘特图 | 16 项任务、6 周排期、按成员着色、4 个里程碑 |
| ▥ 成员任务图 | 4 人分工、6 周负载热力图、过载/闲置预警 |
| ◇ UML 图 | 用例图 + 时序图 |
| ✦ AI 助手 | 6 项智能能力 + 对话演示 |

## 本地运行

直接双击 `index.html`，或在项目目录启动任意静态服务器：

```bash
# 用 Python
python -m http.server 8080

# 或用 Node
npx serve .
```

## 技术栈

- 纯 HTML / CSS / JavaScript（无框架、无构建、无后端）
- 数据通过 `localStorage` 保存在本机浏览器
